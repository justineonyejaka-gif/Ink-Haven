# Ink Haven

All files sit in one flat folder, no sub-folders, so they upload easily from a phone.

Upload every file here to the top level of your GitHub repository (replace the ones that exist), then wait a minute and open your site.

Check it worked: open `manifest.webmanifest` and `icon-192.png` on your site link. Both should open. Then use the browser menu: Install app.

When you upload a newer index.html later, change VERSION in sw.js (for example inkhaven-v3).
