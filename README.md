# Ink Haven

A home for every idea. A phone-first writing app in a single file (`index.html`).

## Put it online (GitHub Pages)
1. Create a repository on GitHub and upload everything in this folder (keep `index.html` at the top level).
2. Open the repository's Settings, then Pages. Choose the main branch and the root folder, then Save.
3. After a minute or two GitHub shows your link. Open it on your phone.

## Good to know
- Your writing is saved inside the browser on the device you use. It does not sync between devices. Export what matters (Word, EPUB, HTML, Markdown or text).
- AI help needs a small server with a key, so it only works inside Claude for now.
- Voice typing and read aloud depend on your browser. Use Chrome, Edge or Safari with the microphone allowed.
- Importing Word, PDF and scanned pages loads its tools from the internet the first time.
